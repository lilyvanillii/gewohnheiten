# Gewohnheiten

Mein eigener Habit-Tracker als Web-App fürs iPhone.

**App öffnen:** https://lilyvanillii.github.io/gewohnheiten/
In Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Alle Einträge bleiben auf dem Gerät gespeichert. Eine Sicherung als Datei gibt es unter den Reglern oben links → Datensicherung.
