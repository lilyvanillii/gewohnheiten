# Gewohnheiten

Mein eigener Habit-Tracker als Web-App fürs iPhone.

**App öffnen:** https://lilyvanillii.github.io/gewohnheiten/
In Safari öffnen → Teilen → „Zum Home-Bildschirm“.

Alle Einträge bleiben auf dem Gerät gespeichert. Eine Sicherung als Datei gibt es unter den Reglern oben links → Datensicherung.

## Trinken

Eigene App, um Getränke zu tracken (Wasser, Tee, Kaffee, Saft, Schorle und eigene).

**App öffnen:** https://lilyvanillii.github.io/gewohnheiten/trinken/
Ebenfalls in Safari öffnen → Teilen → „Zum Home-Bildschirm“. Funktioniert unabhängig vom Habit-Tracker, mit eigenen Daten und eigener Sicherung.
